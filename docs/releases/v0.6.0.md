# SynEvid v0.6.0

## Native desktop verification, Git forensics, live MCP workflows, and deterministic reporting

SynEvid v0.6.0 is the cumulative desktop milestone from the v0.1.0 core foundation through the Phase 1-5 delivery line. It brings deterministic repository analysis, native Git history, live forensic workflows, and a production Electron shell into one offline developer experience.

## Highlights

- **Deterministic verification:** BLAKE3-addressed snapshots, canonical outputs, SQLite WAL persistence, corruption recovery, ordered event replay, and explicit `PASS`, `FAIL`, `PARTIAL`, and `UNKNOWN` coverage states.
- **Real repository-to-canvas flow:** Connect a repository, scan it, inspect persisted symbols and semantic edges, open source ranges, simulate unsaved edits, and inspect impact without writing source files.
- **Native Git forensics:** Read loose and packed objects, ref/ofs deltas, branches, tags, merge parents, dirty worktrees, historical snapshots, semantic diffs, blame, bisect, staging, and guarded Git controls without invoking an external Git process.
- **Forensic trajectory timeline:** Persist sessions, workflows, steps, jobs, receipts, simulations, verification results, rollback actions, and replayable live events in the selected repository's SQLite store.
- **Live MCP and AI workflow:** MCP actions use real daemon APIs, persist trajectory receipts, publish ordered activity events, and expose real working-memory/cache metrics without fabricated PASS or token-savings fallbacks.
- **Native Electron desktop:** Run the source app live during development and produce Windows NSIS/portable/MSI, macOS DMG/ZIP, and Linux AppImage/DEB/RPM artifacts with a Rust sidecar, bundled Next.js cockpit, MCP bridge, watchdog, preload isolation, and loopback authentication.
- **Analytics and export:** Generate deterministic structural-health, dead-code, Git-risk, and AI-session reports in JSON, Markdown, HTML, and SARIF with canonical BLAKE3 report digests.

## What changed from v0.1.0 to v0.6.0

### v0.2.0 - Pluggable core, SQLite, and realtime daemon

- Added the pluggable analyzer registry, SQLite migrations, WAL persistence, real incremental edit simulation, workspace detection, safe path traversal, deterministic snapshots, live event transport, recovery receipts, and the WASM plugin policy loader.
- Added explicit error and coverage contracts so unsupported or dynamic constructs are never silently reported as passing.

### v0.3.0 - Code Universe and live blast simulator

- Connected scan, graph, editor, simulator, and canvas data paths to real persisted repository data.
- Added bounded large-graph projection, deterministic layout, semantic source-line edges, real editor overlays, worker-backed graph preparation, and honest `UNKNOWN`/`PARTIAL` coverage.
- Removed demo graph and simulator fallbacks from the connected workflow.

### v0.4.0 - Native Git, Galaxy, and time travel

- Added a pure-Rust `.git` reader for loose objects, packed objects, delta chains, tags, branches, merge parents, and commit DAGs.
- Added virtual historical snapshots that leave the working tree and `HEAD` untouched, plus semantic diff, blame, bisect, staging, commit, branch, checkout, revert, undo, and recovery flows.
- Wired the Git Galaxy, timeline, comparisons, terminal workbench, CLI, MCP, and web UI to the native Git engine.

### v0.5.0 - Timeline, cache, and live MCP

- Added persisted forensic sessions, workflows, trajectory events, edit-to-verify receipts, rollback history, WebSocket/SSE replay, restart recovery, AI activity signals, deterministic trace bundles, and client configuration generation.
- Replaced fabricated MCP simulator/cache results with authoritative daemon responses and truthful outage/error envelopes.
- Added a real six-turn cache acceptance loop and live MCP-to-daemon integration coverage.

### v0.6.0 - Electron desktop and release engineering

- Added live source development through `npm run dev`, without rebuilding the packaged app for every code change.
- Added standalone packaging with the Next.js standalone cockpit, optimized Rust `synevid-ui` sidecar, MCP bridge, and required Node dependencies.
- Added Windows NSIS, portable, and MSI targets; macOS DMG and ZIP targets; Linux AppImage, DEB, and RPM targets; and native-runner CI gates.
- Added daemon watchdog restart reporting, ephemeral loopback bearer authentication, hardened preload isolation, application menu/tray lifecycle, DevTools controls, workspace presets, analytics reports, deterministic report export, artifact verification, and packaged health checks.

## Safety and canvas compatibility

Phase 5 adds desktop orchestration, persistence, reporting, and release controls around the visual workspace. It does not replace or intentionally redesign the existing 2D/3D canvas renderer, animation loop, camera/orbit behavior, WebGL buffers, or canvas styling. Historical, trajectory, and AI activity data are supplied through existing data boundaries.

## Verification

- Focused Rust, MCP, web, Electron, analytics, determinism, architecture, and packaged smoke checks are included in the release gates.
- Native release jobs verify the platform-specific artifact families on Windows, macOS, and Linux runners.
- SHA-256 checksums, SBOM output, and Sigstore-compatible provenance are available without paid signing services.

## Installation

### Windows

- Install with the NSIS `.exe` installer.
- Use the portable `.exe` for no-install execution.
- Use the `.msi` package for managed deployment.

### macOS

- Use the `.dmg` installer or `.zip` archive.
- Unsigned builds may show the normal Gatekeeper warning; right-click and choose **Open** when appropriate.

### Linux

- Use the `.AppImage` for portable execution.
- Use the `.deb` package on Debian/Ubuntu-family systems.
- Use the `.rpm` package on Fedora/RHEL-family systems.

### Development

```bash
npm run dev
```

This starts the live Electron source runtime and local services so source changes can be tested without rebuilding the distributable package.

## Known limitations

- A strict sub-150 ms history-loading claim is not made for every cold loose-object repository; packed warm-path measurements and native CI coverage are tracked separately.
- OS signing and notarization credentials are not included. Artifacts remain buildable and testable without paid certificates, but users may see platform trust warnings.

## Upgrade notes

- Existing repositories remain compatible with the persisted storage migrations.
- Analysis remains read-only with respect to source files and Git history unless an explicit named Git control is selected.
- No canvas source API change is required for v0.6.0 adoption.

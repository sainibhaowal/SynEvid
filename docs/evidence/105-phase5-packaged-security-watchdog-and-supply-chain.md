# Phase 5 packaged lifecycle, security, and supply-chain evidence

## Status

**Phase 5 G5 packaged lifecycle/security and release-bundle gates: PASS for
tested targets on exact source commit `21ba6bf99f4b157dfbbb1db2c35315c169de7a4b`.**
Native Windows, Linux, and macOS CI and the post-merge release-bundle workflow
both completed successfully. This is evidence for the stated tested targets,
not a claim that unsigned binaries avoid operating-system trust warnings.

No paid OS signing or notarization is used. Windows/macOS artifacts remain
unsigned and may show operating-system trust prompts. Sigstore keyless signing
is used only for release checksums/provenance in GitHub Actions; it does not
sign the desktop executable for Gatekeeper or Windows SmartScreen.

## Changes under verification

- The Electron-owned daemon now starts with explicit `--managed-runtime` mode.
  Its app-data directory is storage, not an inferred user repository. Ordinary
  CLI startup retains repository-root activation behavior.
- The watchdog retains `ERR-DAEMON-301` through recovery, retries with bounded
  backoff, and clears the error state only after authenticated health succeeds.
- Packaged smoke exercises context isolation, sandbox/Node isolation, CSP nonce,
  blocked navigation/popups, hostile IPC refusal, missing/invalid daemon tokens,
  native menu/tray actions, daemon termination/recovery, same-repository
  restoration, tray Quit, and clean sidecar shutdown.
- CI invokes desktop tests in each native Electron matrix job. The post-merge
  workflow builds daemon CycloneDX SBOMs, aggregates release artifacts and npm
  SBOMs, verifies SHA-256 sums, keyless Sigstore signature, and SLSA provenance.
  Release publishing remains opt-in on a non-release branch.

## Limitations and claim boundary

- These results apply to the listed runners and artifact formats; other OS
  versions, CPU architectures, and future source revisions require their own
  validation.
- MSI was not the required Windows installer target and is not claimed as
  installer-smoked. Required Windows NSIS/portable, Linux AppImage/DEB, and
  macOS DMG/ZIP targets were built and exercised by the native matrix.
- No OS code-signing or notarization claim is made.
- This change does not modify the 2D/3D canvas renderer, camera, animation, or
  styling.

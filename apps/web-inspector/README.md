# Web Inspector

A lightweight, zero-backend, read-only visual forensic Evidence Board and Blast Radius explorer for Code Autopsy (`autopsy.json` / SARIF) artifacts.

## Usage
Simply open `index.html` directly in any web browser, or serve locally:
```bash
# Direct browser opening:
xdg-open index.html   # On Linux
open index.html       # On macOS

# Or serve via local static server:
npx serve -l 3000 .
```
